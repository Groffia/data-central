Stage 4 of 8 · Data storage

Where data is kept.

Storage keeps data safe, organized and easy to find. At Tamsworth Health, the clean Silver row from Stage 3 is stored, protected and backed up, then moved to cheaper places as it ages.

Sample data for design review.

01 · What

Keep the row safe and findable

The store must keep data accessible, protected, backed up and organized. Database administrators run it, with IT and security.

Tools: A data lake or a cloud warehouse such as Snowflake.

02 · How

Land, organize, protect, back up

The row is written into the store, indexed and split by date so it can be found fast, locked to the right people, and copied to a second place.

Tools: Database indexing and partitioning; access control; a backup in another location.

03 · Why

Not all data needs the fastest shelf

Recent data is opened often, so it stays hot. Older data is opened rarely, so it moves to cheaper tiers. In this sample, that costs far less than keeping everything hot or warm.

Tools: Cloud storage tiers in a warehouse or lake.

04 · When

A retention rule sets the timing

As the row ages, a rule moves it from hot to warm to cold, and archives it when the retention period ends. The people who run storage set the rule.

Tools: Retention policies in the warehouse or lake.

05 · Next

Management

Stage 5 keeps stored data accurate, compliant and private: who may see it, what it means, and when it is archived or deleted.

Tools: Governance, access control and catalog tools.

01 · Where

Two places AI helps

Inside storage, where AI studies how data is used and makes suggestions. Around it, where an agent watches usage and retention.

02 · What

It reads how data is opened

AI analyzes access patterns: which data is opened often, which sits idle. Most reads touch recent data (sample).

Tools: Usage analysis of the store's access log.

03 · Why it matters

It suggests the layout

From those patterns it suggests indexing, partitioning and tiering. A suggestion is not a change; a person decides.

04 · Why it scales

An agent watches all day

It monitors usage and compliance, and adjusts retention, such as moving idle data to cold, only inside rules a person approved.

05 · Next

People approve the rules

The agent acts inside the approved rules; anything outside them waits for a person. Sources keep humans in control of key decisions. Stored data flows on to Stage 5.

01 · Where

The same row, stored for AI

A model that answers from your own data needs somewhere to look things up. Stage 3 handed over text chunks and the numbers that capture their meaning.

02 · Store

Text in one place, numbers in another

The chunk text stays in ordinary storage. Its numbers go into a vector database, built to find things by meaning.

Tools: A data lake or object store for the text; a vector database for the numbers.

03 · Retrieve

A question becomes numbers too

The question is turned into numbers and compared with the stored ones. The closest meaning wins, found fast with approximate nearest neighbor search. This is RAG.

Tools: A vector database with approximate nearest neighbor search.

04 · Protect

Kept current, kept protected

The store is refreshed regularly so answers stay current. Access control and protection still apply to it, as they do to the source data.

05 · Next

Management

Stage 5 governs this store too: who may read it, what it means, and when its data is archived or deleted.
